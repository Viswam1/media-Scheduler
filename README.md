# 🎬 Church Media Team Scheduler

A lightweight, professional scheduling app for church media teams to plan events and assign tasks like camera operation, live mixing, video editing, and more.

Built with **Streamlit** + **SQLite** — no external DB required.

## ✨ Features

- 📊 **Dashboard** — quick overview of events, members, and task progress
- 📅 **Events** — create and manage upcoming services/events
- 👥 **Members** — maintain your media team roster with skills
- ✅ **Task Assignment** — assign members to specific tasks per event
- 📤 **CSV Export** — download task lists for a given event
- 🎨 Clean, professional UI with custom styling
